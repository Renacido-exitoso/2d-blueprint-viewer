#2D Blueprint Viewer

An interactive web viewer designed to load, inspect, and navigate technical 2D blueprints directly in the browser.

## Features
* **Local File Upload:** Inspect blueprint images in standard formats (PNG, JPG, SVG).
* **Interactive Navigation:** Dynamic zoom via mouse wheel and smooth pan controls by dragging the view.
* **Zero Dependencies:** Built with pure Vanilla JavaScript for optimal efficiency and performance.

## Tech Stack
* **HTML5 Canvas / DOM Manipulation**
* **CSS3 Modern Layouts (Flexbox & CSS Grid)**
* **JavaScript (ES6+)**
